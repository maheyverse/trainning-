
# 🍫 The Choco Bean — Coffee & Chocolate Shop

### ☕ Brewed with Passion. Served with Love.

A modern, responsive coffee and chocolate shop website designed using HTML and CSS, featuring a premium chocolate-brown theme, attractive menu cards, and a cinematic café experience.

---

## 🌟 About the Project

The Choco Bean is a fictional café website created to showcase a chocolate and coffee shop's identity, signature menu, special offers, and contact information.

The design combines warm chocolate tones, elegant typography, and visually appealing food photography to create a welcoming online experience.

**Tagline:** Life is Better with Chocolate.

---

## ✨ Features

- Premium chocolate-brown themed design
- Responsive layout for desktop and mobile devices
- Sticky navigation bar
- Attractive hero section with background imagery
- Signature coffee and chocolate menu
- Product images and pricing
- About Us section
- Special chocolate combo offer
- Contact and shop information
- Smooth scrolling navigation
- Hover animations and interactive buttons

## 🚀 How to Run the Project

### Method 1: Using a Browser

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

### Method 2: Using VS Code

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
